# Capstone (individual)

Team work lives in a separate team repo. This directory is where you record:
- your individual contributions (notes, experiments, design deltas), and
- a pointer to the team repo state (`capstone/team-pointer.json`).

## Team repo pointer

Choose one:
- Submodule: `capstone/team/` points at the team repo (optional).
- URL: put the team repo URL (one line) in `capstone/team_repo.txt`.

The `pre-commit` hook tries to update `capstone/team-pointer.json`.
